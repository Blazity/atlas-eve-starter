# Frontend Engineer Rubric

Criteria:

- Frontend architecture: React components, UI composition, and maintainability.
- TypeScript delivery: typed contracts, strictness, and safe refactors.
- Quality and testing: accessibility, automated tests, and release confidence.
- Collaboration: product/design handoff and pragmatic communication.
